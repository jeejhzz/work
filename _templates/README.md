# 템플릿

새 매뉴얼 문서를 작성할 때 여기서 복사해서 시작합니다.

| 템플릿 | 언제 사용 |
|---|---|
| [업무매뉴얼-템플릿.md](업무매뉴얼-템플릿.md) | 반복 수행하는 일반 업무 (채용 전략, 인원 현황/계획 등) |
| [회의체운영-템플릿.md](회의체운영-템플릿.md) | 타운홀, 노사협의회, 간담회 등 회의체 운영 |
| [법정업무-템플릿.md](법정업무-템플릿.md) | 전문연구요원, 기업부설연구소 등 법정 기한·요건이 있는 업무 |

## 사용법

1. 해당 업무 폴더(`NN-업무명/`)에 템플릿 파일을 복사하고 `번호-제목.md`로 이름을 바꿉니다.
2. `[ ]` 표시된 부분을 채우고, 해당 없는 절은 삭제합니다.
3. 문서 첫머리 메타 표의 `문서 상태`와 `최종 수정일`을 갱신합니다.
4. 해당 업무 폴더의 `README.md` 문서 목록에 새 문서를 추가합니다.

템플릿 자체를 개선했다면 이미 작성된 문서에 소급 적용할 필요는 없습니다. 새 문서부터 반영하면 됩니다.
