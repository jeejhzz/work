## 인원 현황 대시보드 · 조직도

실제 재직 인원 데이터를 바탕으로 한 **인원 현황 대시보드**와 **편집 가능한 조직도**는 [`../HR-업무매뉴얼.html`](../HR-업무매뉴얼.html)의 "07 · 인원 현황 관리" 안에서 사용합니다.

- 조직별 인원·구성, 남녀 비율, 연령 분포, 고용형태 분포, 연구원 현황(실질 R&D / 산기협 등록 케이스별)을 한 화면에서 확인
- 조직도는 박스를 눌러 이름 변경, 하위 조직·구성원 추가/삭제, 신규입사·부서이동·인턴·겸직 표시를 바로 편집 가능
- 기준일: 2026-07-15 업로드된 인원 명단 스냅샷 (인원 변동 시 최신 명단으로 다시 만들어야 함)
