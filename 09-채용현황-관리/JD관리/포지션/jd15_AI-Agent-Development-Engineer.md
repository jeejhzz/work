# AI Agent Development Engineer

## 직무소개
디노티시아 제품개발그룹은 벡터 데이터베이스와 RAG 시스템을 기반으로 차세대 AI 플랫폼을 개발합니다. AI Agent Development Engineer는 AI 에이전트를 활용해 개발 및 업무 프로세스를 자동화하고, 다양한 도구와 시스템을 유기적으로 연결하는 AI Agent 플랫폼을 구축합니다. CLI 및 웹 기반 AI Agent 개발, Multi-Agent 협업, Tool Calling, Context Management 등 Agentic AI 기술을 활용하여 지능적이고 효율적인 AI 워크플로우를 구현합니다. Vector DB·RAG와 AI Agent를 결합한 실서비스 적용 가능한 차세대 AI 시스템을 함께 만들어갈 분을 환영합니다.

## 담당업무
- CLI 또는 웹 기반 AI Agent 소프트웨어 설계 및 개발
- AI Agent를 활용한 개발 및 업무 자동화 솔루션 개발
- MCP 기반 Tool Calling 기능 개발 및 외부 시스템 연동
- 멀티 에이전트 기반 Agentic Workflow 설계 및 개발
- Context Management를 통한 AI Agent 작업 연속성 및 상태 관리
- Vector Database 및 RAG 시스템과 AI Agent 연계 기능 개발
- AI Agent 간 협업 및 Task Delegation 구조 설계
- 개발 조직과 협업하여 AI Agent 플랫폼 고도화 및 서비스 적용

## 자격요건
- 컴퓨터공학, 전기전자공학 또는 관련 분야 학사 이상
- AI Agent 또는 업무 자동화 소프트웨어 개발 경험
- Python, C++ 등 프로그래밍 언어를 활용한 개발 경험
- CLI 또는 웹 애플리케이션 개발 경험
- AI Agent, Tool Calling, 멀티 에이전트 시스템에 대한 이해
- Context Management 및 분산 시스템 기반 Task 관리 이해
- AWS, GCP 등 클라우드 또는 분산 시스템 개발 경험
