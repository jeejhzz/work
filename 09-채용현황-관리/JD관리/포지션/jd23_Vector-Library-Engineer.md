# Vector Library Engineer

## 직무소개
디노티시아 Vector Platform 팀은 다양한 데이터베이스 및 실행 환경에서 대규모 벡터 데이터를 효율적으로 처리·검색하기 위한 라이브러리를 개발합니다. Vector Library Engineer는 디노티시아의 VDPU(Vector Data Processing Unit) Hardware에 최적화된 벡터 검색 및 연산 알고리즘을 구현하고, 플랫폼 관점에서 VDPU의 활용 범위와 적용 가능성을 확장하는 소프트웨어 레이어를 설계·개발합니다. 알고리즘과 시스템 소프트웨어 관점에서 성능, 확장성, 이식성을 종합적으로 고려하며, 기술적 완성도와 높은 코드 품질을 추구하는 분을 환영합니다.

## 담당업무
- VDPU에 최적화된 벡터 처리 및 검색 기능 구현
- 고성능 Vector Index 및 검색 알고리즘 연구 및 구현
- Vector Data Processing/Search 라이브러리 설계 및 개발
- 플랫폼 관점에서 VDPU 활용을 확장하기 위한 기능 설계 및 개선
- 다양한 데이터베이스 및 실행 환경과의 연동 및 통합 개발
- 성능, 메모리 사용량, 지연 시간 관점의 분석 및 최적화
- 대규모 벡터 데이터 처리를 위한 벤치마킹 및 성능 검증

## 자격요건
- C++ 기반의 시스템 프로그래밍 역량
- 자료구조, 알고리즘, 운영체제에 대한 탄탄한 이해
- Linux 환경에서의 개발 경험 및 git, docker 등 협업 도구 활용 능력
- 전산/컴퓨터공학 또는 관련 분야 학사 이상

## 우대사항
- 고성능 시스템 소프트웨어, 공통 처리 라이브러리, 미들웨어 개발 경험
- Vector Search 또는 ANN(Approximate Nearest Neighbor) 알고리즘 관련 연구/개발 경험
- 하드웨어 가속기 환경을 고려한 소프트웨어 최적화 경험
- 다양한 언어(C/C++, Rust 등) 기반 시스템 연동 또는 바인딩 개발 경험
- AI 기반 개발 도구를 활용한 코드 작성·분석·디버깅 경험
