# Firmware Software Engineer

## 직무소개
디노티시아 System SW 팀은 회사의 모든 제품을 위한 런타임, 디바이스 드라이버, 펌웨어, 고성능 컴퓨팅 라이브러리를 개발하며 전체 소프트웨어 플랫폼을 구축합니다. Firmware Software Engineer는 RISC-V 기반 AI 가속기 SoC를 위한 저수준 펌웨어를 설계·개발·검증하고, Host-side 도구 및 가상 플랫폼 환경을 구축하며, 플랫폼 관리와 보안 기능을 구현합니다. Bootloader, PCIe Endpoint, PLDM, Secure Boot, Virtual Platform 등 다양한 영역에서 하드웨어와 긴밀히 협업하여 안정적이고 고성능의 펌웨어 솔루션을 완성합니다. 임베디드 시스템의 깊이 있는 개발 경험을 통해 AI 가속기의 신뢰성과 성능을 극대화하고 싶은 분을 환영합니다.

## 담당업무
- RISC-V 기반 Bootloader, Early/Runtime Firmware 설계 및 개발
- PCIe Endpoint 펌웨어, DMA 엔진, Command Queue 구현 및 Bring-up
- PLDM 기반 플랫폼 관리 및 모니터링 펌웨어 구현 (MCTP over PCIe/SMBus)
- Root of Trust, Secure Boot, Chain of Trust 구현
- Host PC용 CLI 디버그/제어 도구 및 펌웨어 서비스 계층 개발
- QEMU, SystemC 등 가상 플랫폼 환경 구축 및 펌웨어 검증 플로우 자동화
- FPGA/실리콘 Bring-up 지원 및 하드웨어 팀과의 협업
- 메모리·전력·성능 최적화 및 기술 문서화

- ARM 또는 RISC-V 아키텍처에 대한 깊은 이해
- PCIe, PLDM, Secure Boot 관련 경험 또는 이해
- Linux CLI 도구 개발 또는 가상 플랫폼(QEMU, SystemC) 경험
- 복잡한 저수준 시스템 디버깅 및 문제 해결 능력
