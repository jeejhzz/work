# SoC Firmware Engineer

## 직무소개
디노티시아 SoC 그룹은 자사 AI 가속기 SoC의 Pre-Silicon 검증부터 Post-Silicon bring-up, 양산 지원까지 Firmware 전 영역을 담당합니다. SoC Firmware Engineer는 Internal/External IP 검증용 Software 개발, On-chip Firmware Architecture 설계, Bootloader, Device Driver, Multi-core Data Processing Firmware 개발 등을 수행하며, Hardware 팀 및 3rd party와의 긴밀한 협업을 통해 SoC의 안정적 동작과 최적 성능을 실현합니다. SoC 개발 Full Cycle에 대한 깊이 있는 이해를 가진 분을 환영합니다.

## 담당업무
- Internal / External IP 검증용 Software 작성 및 FPGA/Emulator 기반 IP 검증
- SoC boot-ROM code 개발 및 Hardware 검증 협업
- On-chip Firmware Architecture 설계 및 Reference Firmware code 개발 (Bare-metal/RTOS/Embedded Linux)
- Bootloader, Device Driver, Communication Protocol 개발 및 최적화
- Multi-core processor를 활용한 Data-processing Firmware 개발
- Post-silicon Bring-up 지원 및 Firmware issue 분석·해결
- 3rd party와의 Chip final-test code 개발 및 양산 지원
- 유관 부서 및 3rd party와의 긴밀한 협업

## 자격요건
- 전자공학, 컴퓨터공학 또는 관련 전공 학사 이상
- Firmware 개발 경력 10년 이상
- C/C++ 프로그래밍 및 Python 등 Scripting 언어 역량
- DDR, PCIe, UCIe 등 High-speed IP에 대한 이해 및 실무 경험
- SoC/Computer Architecture에 대한 높은 이해도 및 Hardware Debugging 능력
- 탁월한 문제 해결 능력과 커뮤니케이션 스킬

## 우대사항
- SoC High-speed IP (DDR, PCIe, UCIe 등) Bring-up 경험
- Software Architecture 설계 경험
- Linux Device Driver 개발 경험 (특히 PCIe Driver)
- Emulator 환경에서의 Firmware 개발 경험
- SoC 개발 Flow 및 양산 칩 경험
