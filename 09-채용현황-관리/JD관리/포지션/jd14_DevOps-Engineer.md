# DevOps Engineer

## 직무소개
디노티시아 Engineering 팀은 개발부터 테스트, 배포, 운영까지 전 과정을 자동화하고 표준화하여 엔지니어들이 안정적으로 제품을 개발·운영할 수 있는 플랫폼과 인프라를 구축합니다. DevOps Engineer는 GitHub 및 Jenkins 기반 CI/CD 파이프라인, Kubernetes 중심 실행 환경을 운영·개선하며, 코드 품질 관리, 테스트 자동화, 배포 안정성 강화를 통해 개발 생산성과 시스템 신뢰성을 높입니다. 또한 VDPU 개발을 위한 FPGA/ASIC 환경과 LLM 학습을 위한 DGX 기반 MLOps 플랫폼을 운영합니다. IT 개발 환경과 사내 인프라를 구축·관리하는 데 열정이 있는 분을 환영합니다.

## 담당업무
- GitHub/Jenkins 기반 CI/CD 파이프라인 운영 및 개선
- Kubernetes 환경에서의 서비스 및 빌드/테스트 워크로드 운영
- SonarQube, 테스트 자동화 등을 통한 코드 품질 관리
- CI/테스트/운영 지표 시각화를 위한 대시보드 개발
- FPGA/ASIC 기반 VDPU 개발·테스트 파이프라인 운영
- DGX 서버 기반 GPU 클러스터 환경 운영
- 다양한 팀과 협업하여 내부 플랫폼 안정성 개선 및 DevOps 문화 확산

## 자격요건

- Kubernetes 클러스터 운영에 대한 기본 이해
- CI/CD 및 Linux 기반 서비스 운영 경험
