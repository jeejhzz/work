# Vector Database Engineer

## 직무소개
디노티시아 Data 그룹은 벡터 데이터가 생성·저장·검색·확장되는 전 과정을 책임지며, AI가 단기 추론을 넘어 장기 기억과 의미 기반 검색을 수행할 수 있는 기술적 토대를 구축합니다. Vector Database Engineer는 수십억 규모의 벡터 데이터를 효율적으로 저장하고 초고속으로 검색할 수 있는 고성능 Vector Database 코어 엔진을 개발합니다. Vector Index 알고리즘, 분산 아키텍처, 성능 최적화 등 핵심 기술을 연구·개발하며, AI 시스템의 장기 기억 기능을 실현하는 데 기여합니다. 코드 품질과 시스템 성능에 대한 높은 기준을 가지고 팀과 협업하며 기술적 도전을 즐기는 분을 환영합니다.

## 담당업무
- Vector Database 코어 엔진 설계 및 개발
- 고성능 Vector Index 알고리즘 연구 및 구현
- 분산 시스템 아키텍처 설계 및 최적화
- 대규모 데이터 처리를 위한 성능 튜닝 및 벤치마킹

## 자격요건
- 전기전자 및 전산, 컴퓨터 분야 석사 이상 (또는 이에 준하는 연구/개발 경력)
- C++ 또는 Rust를 활용한 시스템 프로그래밍 능력
- 자료구조, 알고리즘, 운영체제에 대한 깊이 있는 이해

## 우대사항
- RDBMS, NoSQL 등 데이터베이스 시스템 설계 및 개발 경험
- 고성능 시스템 소프트웨어 프로젝트 수행 경험
- 벡터 검색, ANN(Approximate Nearest Neighbor) 알고리즘 관련 연구 또는 개발 경험
- Database & Storage Systems 관련 학회/저널 논문 경험 (VLDB, SIGMOD, ICDE, FAST 등)
- Systems & Architecture 관련 학회/저널 논문 경험 (SOSP, OSDI, ASPLOS, MICRO 등)
