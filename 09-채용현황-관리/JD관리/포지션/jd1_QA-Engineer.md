# QA Engineer

## 직무소개
디노티시아 QA Engineer는 하드웨어(VDPU 가속기 보드)와 소프트웨어(드라이버, Firmware, Runtime, SDK)가 결합된 제품의 품질 기준을 정의하고 검증 체계를 설계합니다. PCIe 디바이스 드라이버, 호스트 SDK, API 레벨의 기능·성능·신뢰성 검증을 주도하며, CI/CD와 연동된 Hardware-in-the-Loop(HIL) 자동화 테스트 프레임워크를 구축합니다. DMA 기반 고속 데이터 전송의 무결성 검증부터 장기 신뢰성 테스트까지, 제품 출하 전 마지막 품질 관문을 담당합니다.

## 담당업무
- QA 전략 수립 및 테스트 프로세스 초기 셋업 (테스트 케이스 표준화, Defect Lifecycle, Exit Criteria)
- PCIe 디바이스 드라이버, 호스트 SDK, API 레벨 기능·비기능 테스트 주도
- 고속 데이터 전송(DMA) 시 데이터 무결성 검증 및 비트 에러율(BER) 측정
- 메모리 누수, Race Condition, 커널 크래시 등 시스템 레벨 이슈 분석
- 성능(Throughput, Latency, IOPS) 벤치마크 환경 구축 및 프로파일링
- 장기 신뢰성(Aging) 스트레스 테스트 설계 및 실행
- CI/CD 파이프라인 연동 HIL 기반 자동화 테스트 프레임워크 구축

## 자격요건
- 임베디드 시스템, 반도체, 또는 가속기 분야 SW/시스템 QA 경력 7년 이상
- Linux 커널 및 디바이스 드라이버 구조에 대한 깊은 이해와 디버깅 능력
- Python, C/C++ 등을 활용한 테스트 자동화 스크립트 개발 능력
- PCIe 아키텍처(BAR, Interrupt, DMA, Virtualization) 이해
- 초기 프로젝트에서 QA 프로세스 및 자동화 인프라 구축 경험
- 뛰어난 커뮤니케이션 역량

## 우대사항
- AI/반도체 하드웨어 가속기 관련 소프트웨어 스택 검증 경험
- Jenkins, GitLab CI 등을 활용한 HIL 연동 CI/CD 파이프라인 구축 경험
- Valgrind, gdb, ftrace, perf 등 Linux 디버깅 툴 활용 능력
- 소프트웨어 개발 경험(C/C++ 또는 Firmware)에서 QA로 전환
- Jira, Confluence 등 협업 툴 워크플로우 커스텀 셋업 경험
