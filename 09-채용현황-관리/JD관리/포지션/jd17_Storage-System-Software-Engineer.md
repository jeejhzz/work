# Storage System Software Engineer

## 직무소개
디노티시아 제품개발그룹은 벡터 데이터가 생성·저장·검색·확장되는 전 과정을 책임지며, AI가 장기 기억과 의미 기반 검색을 수행할 수 있는 기술적 토대를 구축합니다. Storage System Software Engineer는 차세대 AI 및 LLM 시스템을 위한 고성능·대규모 분산 스토리지 시스템을 개발합니다. Ceph 기반 분산 스토리지 아키텍처를 확장·고도화하여 대규모 벡터 데이터와 AI 워크로드에 최적화된 저장·입출력·내구성·확장성을 제공하는 AI Storage Layer를 구축합니다. 분산 스토리지 시스템의 내부 구조를 깊이 이해하고 AI/Vector DB 워크로드 특성을 반영한 차세대 스토리지 기술을 함께 만들어갈 분을 환영합니다.

## 담당업무
- K8s 기반 DB/Storage-as-a-Service 및 AgentOps 솔루션 개발
- Ceph 기반 AI Storage 시스템 아키텍처 설계 및 개발
- Vector Database 및 LLM 워크로드를 고려한 스토리지 구조 및 I/O 경로 최적화
- 분산 스토리지 시스템의 성능, 안정성, 확장성 개선
- 메타데이터 관리, 복제/Erasure Coding, 캐싱 전략 등 핵심 기능 개발
- 대규모 분산 환경에서의 장애 대응, 데이터 무결성 및 복구 메커니즘 설계
- 벤치마킹 및 성능 분석을 통한 병목 구간 도출 및 최적화
- Storage–DB–AI 시스템 간 인터페이스 및 연동 구조 설계

## 자격요건
- 컴퓨터공학 또는 전기전자공학 석사 이상 (또는 이에 준하는 연구/개발 경력)
- 분산 시스템, 운영체제, 파일 시스템, 스토리지 구조에 대한 탄탄한 기본기
- Linux 환경에서의 Low-level 시스템 개발 경험
- 대규모 데이터 처리 및 성능 최적화에 대한 이해와 관심
- AI Agent를 활용한 솔루션 개발 및 서비스 운영 경험

## 우대사항
- Ceph, Lustre, GlusterFS 등 분산 스토리지 시스템 사용 또는 개발 경험
- RDBMS, NoSQL, Vector DB 등 데이터베이스 스토리지 레이어 이해
- AI/ML 또는 Vector Search(ANN) 워크로드 특성에 대한 이해
- C/C++ 또는 Rust 기반 시스템 프로그래밍 역량
- 고성능 스토리지 또는 시스템 소프트웨어 프로젝트 경험
- Kubernetes 환경에서의 스토리지 연동 경험
- 스토리지·시스템·아키텍처 관련 학회/논문 경험 (FAST, SOSP, OSDI, ASPLOS, VLDB 등)
