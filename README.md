# HR 업무 매뉴얼

인사(HR) 업무의 워크플로우를 인수인계가 필요 없을 정도로 상세하게 기록하는 저장소입니다.
"이 문서만 읽으면 처음 온 사람도 그 업무를 수행할 수 있다"를 목표로 작성합니다.

| 02 | 타운홀미팅 진행 | [`02-타운홀미팅/`](02-타운홀미팅/) | 회의체 운영 |

## 폴더 구조 규칙

```
NN-업무명/
├── README.md          # 이 업무의 개요 + 폴더 내 문서 목록 (문서맵)
├── 01-업무개요.md      # 업무 정의, 목적, 연간 사이클
├── 02-*.md            # 세부 절차 문서 (번호를 붙여 순서대로)
└── 자료/              # 양식, 서식, 과거 결과물, 참고자료
```

- 폴더 안 문서는 `번호-제목.md` 형식으로 만들어, 읽는 순서가 곧 업무 순서가 되게 합니다.
- 문서가 많아지면 하위 폴더(예: `05-전문연구요원/편입/`, `05-전문연구요원/복무관리/`)로 쪼갭니다.
- 엑셀·PPT 등 바이너리 자료는 각 업무 폴더의 `자료/`에 넣고, md 문서에서 링크합니다.

## 공통 폴더

| 폴더 | 용도 |
|---|---|
| [`_templates/`](_templates/) | 새 문서를 쓸 때 복사해서 시작하는 표준 템플릿 |
| [`_common/`](_common/) | 여러 업무에 걸치는 공통 자료 (용어집, 시스템 목록, 연간 캘린더) |

## 문서 작성 규칙

1. **템플릿에서 시작** — `_templates/`에서 업무 성격에 맞는 템플릿을 복사해 채웁니다.
   - 반복 수행하는 일반 업무 → `업무매뉴얼-템플릿.md`
   - 타운홀·노사협의회·간담회 등 회의체 → `회의체운영-템플릿.md`
   - 신고·기한이 있는 법정 업무 → `법정업무-템플릿.md`
2. **문서 상태 표시** — 문서 첫머리 메타 표의 `상태`에 `초안` / `검토중` / `확정` 중 하나를 적습니다.
3. **변경 이력** — 절차가 바뀌면 문서를 고치고, 문서 하단 변경 이력 표에 날짜와 변경 내용을 한 줄 남깁니다.
4. **실명·개인정보 금지** — 구성원 개인정보(주민번호, 연봉, 평가 등)는 절대 기록하지 않습니다. 담당자는 이름 대신 역할(예: "인사팀 채용 담당자")로 적습니다.
5. **비밀번호·계정 금지** — 시스템 접속 정보는 "어디에 있는지"(예: 팀 비밀번호 관리 도구)만 적고 값은 적지 않습니다.

## 작성 우선순위 가이드

인수인계 관점에서 아래 순서로 작성하는 것을 권장합니다.

1. **기한을 놓치면 법적 문제가 생기는 업무** — 전문연구요원, 기업부설연구소, 노사협의회
2. **정기 반복 업무** — 인원 현황 관리, 타운홀미팅
3. **연 단위 기획 업무** — 채용 전략, 인원 계획
4. **수시 업무** — 구성원 간담회
